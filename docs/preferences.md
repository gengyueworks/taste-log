# 审美判断体系

这份文档是这个库的地基。收录哪些站、为什么收、写判断时看哪些维度，都从这里来。

它记录的是一套**个人**偏好。不假装客观，也不打算说服谁。公开出来是因为：大部分设计合集只告诉你"这个好看"，很少有人把"我凭什么这么认为"摊开写。摊开写才可能被反驳，被反驳才可能进步。

---

## 一、底色：白底

明确偏好白色底色。

不喜欢偏黄、偏土、旧纸感过强的底色。页面打开的第一感觉应该是清爽、明亮、轻。

唯一站得住的暗色方向是"星际流光暗黑感"——流光轨迹 + 宇宙空间感 + 黑暗中发光（参考 Huly）。除此之外的深色页面，多数是在用暗色掩盖结构问题。

## 二、结构：排列感

喜欢有排列感的设计。信息被整理得很清楚，一眼能看到顺序、层级和版式秩序。

不喜欢页面只是"堆元素"。

判断一个页面有没有排列感，最简单的办法：眯起眼睛看，如果还能看出模块的分组和主次，就有；如果糊成一片，就没有。

Apple 是这条的天花板——不是因为它好看，是因为它在信息量极大的情况下还能让人一眼看清顺序。

## 三、气质：克制的科技感 + 编辑感

两条同时成立：

**科技感这一侧**：喜欢工具感、电脑感、界面感。核心配方是「分层块状 + 蓝色点亮 + 克制动效」，三样缺一样就散（Linear 是基准线，Spline 是升级版）。

**内容感这一侧**：喜欢编辑感、内容感、作者感。图片、文字、留白之间的关系应该是被编辑过的，不是排出来的（Kinfolk）。

不喜欢很模板化、很普通创业首页的气质。

## 四、两条母本线

长期收下来，稳定分成两条：

### 主站气质线 · 母本 Kinfolk

关键词：编辑感、生活世界感、作者型主站。

适合：个人主站首页、内容型网站、有作者身份的项目。

### 写作产品线 · 母本 Craft

关键词：温柔工具感、可爱但不幼稚、写作 / 日记 / 记录类产品。

适合：写作工具、日记产品、需要人愿意长期停留的界面。

补充方向：

- 抓模块入口 → Land-book
- 科技秩序感 → Linear
- 个人主页 / 轻档案感 → Curvit

## 五、长文阅读页的特殊标准

长文页和其他页不是一套标准。它的设计目标不是展示花样，是**保护注意力**。

好的长文页：

- 目录跟着阅读状态走，但存在感压得很低——安静陪读，不是不断打断
- 正文宽度和留白克制，阅读节奏稳定
- 没有太多跳色、卡片、噪音模块
- 更像"阅读器"，不像"营销页"

简洁不是空，是把干扰项压到很低。文字够强的时候，页面越安静，内容越容易被信任。

反过来说：如果一个页面必须靠视觉救场，先回去改文案。

参考：Machines of Loving Grace、Sam Altman Blog、LoveFrom。

## 六、颜色的用法

学 Possible 的做法：品牌色不铺满，只出现在 Logo、链接、导航和少量强调位置。

采样值：主蓝 `#1EBBF0`，辅助蓝 `#54B7F9`。

这个库自己用的是 `#275ea5`，更深、更安静，配白底不刺眼。

一个页面里的强调色出现次数，超过五处就该重新想想哪些是真的需要强调。

## 七、明确不喜欢的

- 页面发黄、发土
- 只有热闹，没有秩序
- 模板化 SaaS 首页
- 没有排列感，没有结构
- 只靠流行渐变和 3D 插画撑起来
- **把工作说明和浏览入口混在一起**

最后一条是长期高频错误，单独说：

浏览型页面就该清清爽爽，打开直接看内容、点链接。过程笔记、工作总结、原始口述属于工作文档，不该占据浏览入口。用"文字说明"代替视觉交付，是习惯性偷懒。

这个库的首页严格执行这条——判断默认折叠，想看才展开。

## 八、还在收的维度

以下几条样本量还不够，暂时不下结论：

- 版式密度的舒适区间
- 留白程度和内容类型的对应关系
- 字体气质的偏好边界
- 卡片与模块感的使用时机
- 插画使用方式
- 转化区的语气分寸
- 哪些项目适合更克制，哪些适合更强产品感

每满 10 个新样本会回头修订一次这份文档。

## 怎么用这份文档

如果你要给自己也建一个类似的库，请把这里的结论当作个人样本来阅读，再建立自己的偏好。

值得借鉴的是**结构**：

1. 先记"你直觉上喜欢它哪一块"（原话，不修饰）
2. 再记"它客观呈现出什么视觉 / 交互特点"
3. 再判断"它适合什么类型的项目"
4. 最后抽"哪个细节以后能拿走用"

四层写下来，一个月后回看还能用。只写第一层，一周后就只剩链接了。
