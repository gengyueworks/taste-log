> 这是从「每天刷网站、随手记判断」里长出来的第二层资产。

## 三、卡片

### 1. Spline · 科技感

- **链接**：https://spline.design/
- **喜欢哪一块**：Linear 黑色分层结构的升级版。蓝色点亮的部分一块一块动起来，有流光感。
- **为什么好**：科技感的核心配方「分层块状 + 蓝色点亮 + 克制动效」在这里全部成立，而且动效节奏克制，不喧宾夺主。
- **能拿走**：深色底 + 分区块状 + 蓝点亮点的结构，是「高级科技感」的通用骨架。
- **收录日期**：2026-03-25

### 2. Huly · 星际流光暗黑科幻

- **链接**：https://huly.io/
- **喜欢哪一块**：流光和像宇宙一样向上延伸的感觉，想到《星际穿越》里土星环的流动感。Dark Mode 特别漂亮，有「在黑暗中发光」的感觉。
- **为什么好**：这是唯一站得住的暗色方向——不是用暗色掩盖结构问题，是流光轨迹 + 宇宙空间感本身就成立。
- **能拿走**：深色页面想高级，先想「黑暗中发光」，别想「纯黑底 + 白字」。
- **收录日期**：2026-03-25

### 3. division-code · 干净主页极简科幻

- **链接**：https://division-code.netlify.app/
- **喜欢哪一块**：干净主页类型，极简而且很科幻，整体很酷。
- **为什么好**：高留白、低噪点，冷静但酷——科幻感不一定要暗色，白底也能做出来。
- **能拿走**：干净主页的克制路线：少元素、大留白、精确对齐。
- **收录日期**：2026-03-25

### 4. Rive · 开场交互装置

- **链接**：https://rive.app/
- **喜欢哪一块**：一打开有火箭飘出来，开场互动很有记忆点。
- **为什么好**：第一屏的记忆点不靠配色堆，靠一个和产品语义相关的交互装置。
- **能拿走**：AI 网站 / 产品首页可以配一个「和品牌语义相关」的开场交互（火箭、宇宙飞船方向）。
- **收录日期**：2026-03-25

### 5. s-p.studio · 摄影照片墙

- **链接**：https://s-p.studio/
- **喜欢哪一块**：照片墙和换灯片式的展示方式，布局一排一排，风格极简。点开大图再回到列表，层级感非常舒服。
- **为什么好**：摄影站的价值全在「浏览动线」——网格浏览 → 点开大图 → 返回原位，每一步都顺。
- **能拿走**：旅行个人网站的摄影照片墙模块可以直接借鉴这套「网格 + 大图 + 顺滑返回」的动线。
- **收录日期**：2026-03-25

## 四、卡片背后的判断标准

整理这批卡时沉淀的判断口径：

1. **先说出喜欢哪一块，再谈风格。** 「很高级」不是判断，说不出具体哪一块，说明还没看懂。
2. **语义优先，不是风格优先。** 女孩与剑那张卡的纠偏证明了：符号 > 配色。
3. **「能拿走」是硬门槛。** 只有欣赏价值、无可迁移细节的，不进卡。
4. **备用 ≠ 低质。** trk、smithfieldcattleco 这类备用卡，是等真实需求出现时直接能调的弹药。
